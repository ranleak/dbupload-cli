# dbupload-cli
A simple Dropbox upload CLI.

Before you run the CLI, it is *WAY* easier to export your Dropbox access token to the environment variables before... rather than have to enter it in. Just run ```export DROPBOX_ACCESS_TOKEN=<your-token-here>``` and you'll be good to go. If you want to check out how to generate an access token, take a look at this guide.

Enjoy!
